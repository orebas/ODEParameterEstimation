# Internal notes

These are engineering notes written while the package was being developed:
investigation records, design discussions, benchmark handoffs and release
checklists. They are kept for the people and tools that work on the package
itself.

They are not user documentation. Many describe code that has since changed,
and none is kept up to date. To learn how to use the package, read the
[manual](https://orebas.github.io/ODEParameterEstimation.jl/dev/).

Some starting points:

- [review_map.md](review_map.md) says where things are in the source.
- [registry_preparation.md](registry_preparation.md) is the checklist and
  validation record for the first registered release.
- [polynomial_solve_mechanics.md](polynomial_solve_mechanics.md) explains how
  the polynomial systems are built and solved.
- Files whose names start with a date are session records, in the order they
  were written.
