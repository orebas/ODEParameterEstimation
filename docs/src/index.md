# ODEParameterEstimation.jl

Estimate ODE parameters and initial conditions from observed time series.
Start with the [installation and minimal example](https://github.com/orebas/ODEParameterEstimation.jl#installation),
[quickstart](https://github.com/orebas/ODEParameterEstimation.jl/blob/main/docs/internal/2026-03-17_user_quickstart.md),
[result contract](https://github.com/orebas/ODEParameterEstimation.jl/blob/main/docs/internal/2026-03-17_results_and_api.md),
and [supported models](https://github.com/orebas/ODEParameterEstimation.jl/blob/main/docs/internal/2026-03-17_supported_models_and_limitations.md).

These reference pages document exported names. The supported workflow and its
limits are described in the guides above; private backend implementation
details remain beside their source. Uncertainty quantification is opt-in,
with [documented calibration limits](https://github.com/orebas/ODEParameterEstimation.jl/blob/main/docs/internal/2026-08-14_estimator_aware_uq.md).
