# M=1 Benchmark Audit

Status: implemented as bounded-physical M=1 benchmark variants on 2026-06-06.

Policy: the paper benchmark should not depend on branch completion. Systems are
accepted as M=1 when their identifiable subspace has one algebraic branch, or
when the benchmark-specific observable variant removes the known physical
branch. The PEB config generated by
`repro/m1_benchmark_2026_06_06/sync_peb_m1.py` sets
`ODEPE_BRANCH_COMPLETION=false`.

```bash

```

`slow_fast_m1`, `biohydrogenation_m1`, and the two observed-control branch
stress systems.


## Local Hardness Smoke

`repro/m1_benchmark_2026_06_06/compare_m1_hardness.jl` runs a clean-data,
single-point, no-polish AAAD probe with branch completion disabled. This is
not a full benchmark result, but it is a useful solve-hardness check.

| Family | Original seconds | M=1 seconds | Speedup | Original max error | M=1 max error |
|---|---:|---:|---:|---:|---:|
| biohydrogenation | 261.1 | 252.5 | 1.0x | 1.0e-2 | 1.0e-2 |
| daisy_mamil4 | 19.5 | 5.5 | 3.6x | 1.1e-2 | 1.0e-7 |
| seir | 44.4 | 17.9 | 2.5x | 1.0e1 | 1.0e1 |
| slow_fast | 12.1 | 5.1 | 2.4x | 4.7e-8 | 3.1e-10 |
| latent_subpopulation | 73.6 | 7.4 | 10.0x | 1.3e-3 | 7.1e-9 |
| receptor_subtype_binding | 223.9 | 6.0 | 37.2x | 9.9e-1 | 1.6e-5 |

SEIR was also checked with bounded polish enabled and `polish_maxtime=120`.
That reduced wall time from 71.1s to 20.3s for `seir_m1`, but both original
and M=1 still had max error near 10 in this local single-point setup. Treat
SEIR as M=1 structurally easier, but still numerically hard.
